# 🏎️ 모바일 레이싱 게임

드레곤플레이트 스타일의 모바일 레이싱 웹게임입니다.  
엄지손가락으로 좌우 드래그하여 차량을 조작하고, 장애물을 피하며 부스터를 수집하여 최고 점수를 달성하세요!

---

## 🎮 게임 방법

| 조작 | 방법 |
|------|------|
| **터치 이동** | 화면을 터치 후 좌우로 드래그 |
| **PC 이동** | 마우스 클릭 후 좌우로 드래그 |
| **일시정지** | 상단 중앙 ⏸ 버튼 |

---

## ⚡ 부스터 시스템

| 레벨 | 속도 배수 | 특수 효과 | 색상 |
|------|----------|-----------|------|
| **1단계** | 1.5× | 속도 증가 | 🟢 초록 |
| **2단계** | 2.0× | 속도 + 장애물 밀쳐냄 (+20점) | 🟠 주황 |
| **3단계** | 2.5× | 속도 + 장애물 파괴 (+50점) | 🔴 빨강 |

- 부스터 지속 시간: **5초**
- 활성 중 아이템 수집 → 레벨 +1 & 시간 **리셋**
- 시간 종료 시 레벨 0으로 초기화

---

## 🎯 점수 시스템

| 행동 | 점수 |
|------|------|
| 장애물 회피 (화면 밖) | +10점 |
| 장애물 밀쳐냄 (2단계) | +20점 |
| 장애물 파괴 (3단계) | +50점 |
| 부스터 아이템 획득 | +100점 |
| 3연속+ 콤보 | 콤보 표시 |

최고 점수는 **LocalStorage**에 자동 저장됩니다.

---

## 🚀 구현된 기능

- ✅ 모바일 터치/드래그 컨트롤 (상대 이동 방식)
- ✅ PC 마우스 드래그 지원
- ✅ 스크롤 애니메이션이 있는 3차선 도로
- ✅ 도로 이탈 시 속도 감소 패널티
- ✅ 장애물 충돌 감지 및 3단계 부스터 반응
- ✅ 시간이 지날수록 난이도 자동 증가
- ✅ 콤보 시스템 (3연속 이상)
- ✅ 플로팅 점수 텍스트 이펙트
- ✅ 부스터 레벨별 오라 효과 + 3단계 맥동 애니메이션
- ✅ 최고 점수 저장 (LocalStorage)
- ✅ 시작 화면 / 일시정지 / 게임 오버 화면
- ✅ 픽셀아트 스타일 차량 그래픽

---

## 🛠️ 기술 스택

- **HTML5 Canvas** – 게임 렌더링
- **JavaScript (Vanilla)** – 게임 로직
- **CSS3** – UI 스타일링 및 애니메이션
- **Touch / Pointer Events** – 모바일 터치 제어
- **RequestAnimationFrame** – 60fps 게임 루프
- **LocalStorage** – 최고 점수 저장
